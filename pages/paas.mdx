# PaaS API

Liara's Platform as a Service (PaaS) API lets you create, deploy and run applications without managing servers.

## Overview

The PaaS API allows you to:

- **Create and manage apps** - Create apps on your chosen platform, plan and network
- **Deploy** - Upload source code and build it, or deploy a ready-made image for `docker` apps
- **Configure apps** - Set environment variables, the port, DNS servers, plans and other settings
- **Turn apps on and off** - Stop or start an app, or restart it
- **Monitor** - Read logs, CPU, memory and network usage, and lifecycle events
- **Manage domains** - Connect custom domains and SSL certificates
- **Manage disks** - Create persistent disks, back them up and restore them

## Key Features

### Platforms

Apps can run on Node.js, Next.js, React, Vue, Angular, static sites, Laravel, PHP, Django, Flask, Python, .NET, Go, or any container image with the `docker` platform.

### Deployment Options

- **Source code**: Upload a `.tar.gz` or `.zip` archive, then create a release from it
- **Container image**: Deploy an existing image to a `docker` app
- **Zero-downtime deployment**: Keep the current release running until the new one is ready
- **Rollback**: Redeploy an earlier successful release

### Persistent Storage

Attach disks to your apps for data that must survive deployments. Back up disks, restore backups and resize disks through the API.

### Custom Domains

Connect your own domains to your apps and get SSL certificates for them.

## Base URL

```
https://api.liara.ir
```

## Interactive Shell

Open a shell in a running app over WebSocket:

```
wss://api.liara.ir/v1/exec?token=<api-token>&project_id=<app-name>&cmd=/bin/bash
```

Add `teamID=<team-id>` for an app that belongs to a team. See the Apps & Deployments reference for details.

## Common Use Cases

1. **CI/CD Integration**: Deploy automatically from your CI/CD pipeline
2. **Scheduled on/off**: Turn non-production apps off outside working hours
3. **Multi-environment Management**: Manage development, staging and production apps
4. **Backup Automation**: Create disk backups on your own schedule

## Getting Started

To start using the PaaS API, you'll need to:

1. Get an API token from the Liara Console
2. Create a network, then create an app in it
3. Upload your source code and create a release
4. Configure domains and environment variables as needed

Explore the API endpoints below to learn more about each operation.
